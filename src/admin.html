Unggah manual

Cadangan kalau internet PC booth bermasalah.

Dipakai kalau internet PC booth bermasalah. Dari PC CS (yang bisa membuka folder hasil booth lewat jaringan bersama), pilih folder hasil, lalu file diunggah lewat website ini ke cloud dan link-nya langsung hidup untuk pelanggan. Pilih folder tanggal (mis. 2026-10-23) untuk mengunggah banyak sesi sekaligus, atau satu folder sesi. Sesi yang sudah terunggah dilewati otomatis.

Masa simpan file

Berlaku untuk sesi BARU. Rekomendasi: 7 atau 15 hari.

Tombol "All … (zip)" di halaman pelanggan

ZIP praktis tapi di sebagian HP (terutama iPhone) harus dibuka dulu. Tanpa ZIP, foto langsung bisa disimpan ke galeri tapi browser mungkin meminta izin unduhan berganda. "Keduanya" menampilkan dua tombol: ZIP, dan "Unduh semua file" yang mengunduh langsung dari cloud (tidak lewat server). Tombol unduh per foto selalu ada.
