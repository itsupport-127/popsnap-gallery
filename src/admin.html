Masa simpan file
Berlaku untuk sesi BARU. Rekomendasi: 7 atau 15 hari.
Tombol "Unduh semua" di halaman pelanggan
ZIP praktis tapi di sebagian HP (terutama iPhone) harus dibuka dulu. Tanpa ZIP, foto langsung bisa disimpan ke galeri tapi browser mungkin meminta izin unduhan berganda. Tombol "Unduh" per foto selalu ada.
Penyimpanan cloud (S3 / Cloudflare R2)
Sesi baru ditaruh di bucket dengan nomor prioritas terkecil yang masih muat; sama prioritas = dibagi rata. Kalau satu penuh atau gagal, otomatis pindah ke yang lain.
Tambah bucket

R2: buat bucket PRIVATE + API token "Object Read & Write". Endpoint ada di halaman R2 (S3 API). Region: auto.

Unggah manual dari PC CS
Dipakai kalau internet PC booth bermasalah. Dari PC CS (yang bisa membuka folder hasil booth lewat jaringan bersama), pilih folder hasil, lalu file diunggah lewat website ini ke cloud dan link-nya langsung hidup untuk pelanggan. Pilih folder tanggal (mis. 2026-10-23) untuk mengunggah banyak sesi sekaligus, atau satu folder sesi. Sesi yang sudah terunggah dilewati otomatis.
